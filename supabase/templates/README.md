# Plantillas de correo KIUBO

Plantillas listas para Supabase Auth (hosted).

- **Magic link** — asunto: `Tu acceso seguro a KIUBO`
- **Confirm signup** — asunto: `Activa tu acceso a KIUBO`
- **Reset password** — asunto: `Recupera tu acceso a KIUBO`
- **Invite user** — asunto: `Te invitaron a KIUBO`

Los botones usan `{{ .ConfirmationURL }}` y el logo público de producción. En Supabase hosted se copian en Authentication → Emails → Templates.

Branding oficial: icono `https://cdn.phototourl.com/free/2026-08-22-d66f0865-834f-4fad-aba9-d7d2de485042.jpg` y logo `https://cdn.phototourl.com/free/2026-08-22-e42cce9a-2046-4bbe-be06-58d84bde4b8e.png`.
