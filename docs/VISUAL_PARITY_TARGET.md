# KIUBO Visual Parity Target

Objetivo de este hito: acercar la interfaz real de KIUBO a los mockups conceptuales aprobados como referencia visual, sin fingir funcionalidades no terminadas ni datos comerciales no verificados.

## Pantallas prioritarias
1. Landing pública: hero blanco, dashboard mock realista, formas coral/naranja/azul, módulos claros, CTA fuerte.
2. Precios: tres planes visualmente diferenciados, Pro destacado, precios provisionales reales del proyecto.
3. Dashboard negocio: layout blanco/navy, KPIs, gráfico semanal, productos top, stock bajo, caja, ventas recientes, acciones rápidas.
4. Onboarding: stepper de 6 pasos, formularios claros, panel lateral de entrega/soporte y estado del trial.
5. KIUBO Control: KPIs plataforma, pipeline, onboarding, clientes por plan, actividad y gestión de negocios.
6. Móvil: no comprimir desktop; reorganizar a una sola columna, cards legibles y navegación touch.

## Reglas
- No mostrar +5.000 clientes, MRR, uptime o testimonios como hechos reales si no existen.
- No presentar SRI como productivo hasta completar firma/transmisión/autorización/RIDE real.
- Mantener Start/Pro/Custom y precios de preview vigentes en código hasta cierre comercial.
- Mantener soporte para reduced motion y accesibilidad básica.
