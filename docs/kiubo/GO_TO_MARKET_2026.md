1. **Web pública** — funciones, precios, cómo funciona, demo.
2. **Aplicación** — POS, inventario, caja, clientes, compras, reportes, branding y Factura cuando aplique.

## Posicionamiento
No vender “el más barato”; vender **alto valor por dólar**: rapidez, diseño moderno, onboarding, soporte cercano y operación integrada.

## Embudo
**Redes / referidos / web / contacto local → Prospecto → descubrimiento → demo → trial → onboarding → cliente → soporte → referido/testimonio.**

Pipeline: `Nuevo → Contactado → Demo → Trial → Cliente / No convertido`.

Registrar canal, necesidad, plan probable, seguimiento, notas, tenant vinculado y progreso onboarding.

## Demo
Objetivo 15–20 minutos. Mostrar venta rápida, stock, caja/reporte y solo los módulos relevantes. Pregunta principal: “¿Qué usas hoy para controlar ventas e inventario y qué te hace perder más tiempo?”

## Qué pedir
### Demo
Nombre/contacto, negocio, ciudad, teléfono/canal, tipo de negocio, necesidad.

### Activar POS
Datos comerciales, sucursales, usuarios, inventario/migración, pagos, logo/colores si aplica.

### Solo Factura/SRI
RUC/datos fiscales, establecimiento/punto, configuración tributaria y firma vigente por flujo seguro. **El RIDE no se pide: KIUBO lo genera.**

## Redes/publicidad
Prioridad inicial: WhatsApp Business → Instagram → TikTok/Reels → Facebook → referidos/contacto local. No gastar fuerte antes de medir conversión y onboarding.

Contenido: ventas rápidas, Excel→inventario, caja/fiados/stock, antes/después, mini tutoriales, casos autorizados y facturación simple cuando esté lista.

Cadencia inicial sugerida: 3 videos cortos/semana, 1–2 piezas/carruseles y stories.

## Mensaje comercial
**Tu negocio no necesita un sistema complicado. Necesita vender rápido y saber qué está pasando.**

Promesa: **Todo tu negocio, en orden.**

## Onboarding
Necesidades → datos → branding → productos/migración → usuarios → caja/pagos → capacitación → SRI si aplica → backup → go-live.

## No hacer
No ofrecer 90 días a todos, no regalar custom ilimitado, no prometer cero errores, no activar SRI sin certificación, no guardar secretos inseguramente, no gastar fuerte en anuncios temprano, no mezclar Barrio MAX y clientes comerciales y no invertir públicamente en marca sin validar.

## Orden de lanzamiento
Producto/backend → validar marca → dominio/correo → redes/WhatsApp → web → piloto fundador → corregir fricción → trial público → publicidad pequeña → escalar.

## Operación legal/comercial
Antes de cobrar públicamente, contratos, cobros, términos, privacidad y titularidad de marca deben quedar bajo persona/entidad legalmente habilitada.
